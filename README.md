# Formula 1 Race Intelligence Dashboard

An interactive Tableau dashboard analyzing Formula 1 race results, driver reliability, team performance, tyre strategies, and podium achievements.

## 🔗 Live Interactive Dashboard
Click below to view the interactive dashboard on Tableau Public:
[View F1 Intelligence Dashboard on Tableau Public](https://public.tableau.com/views/F1RaceIntelligence_17933834512080/Story1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

## 📊 Features & Visualizations
- KPI Cards (Competing Teams, Seasons, Race Outcomes, Circuits)
- Geographic Map (Global Driver Distribution)
- Driver Reliability Analysis (Stacked Bar Chart by DNF Reason)
- Driver Performance Leaderboard
- Team Performance Ranking
- Team Championship Performance Analysis
- Tyre Compound Usage Distribution
- Country-wise Race Participation
- Podium Achievements by Driver and Team
